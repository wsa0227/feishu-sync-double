# 飞书同步插件使用步骤

这是一个 Obsidian 插件，把 Obsidian 的笔记和飞书互相同步。基于开源项目 [ObsidianSync](https://github.com/chenqaq123/ObsidianSync) 二开，主要加了几件事：可以同时管多个知识库、能跟进别人分享的文档更新、右下角有个管理面板。

## 旨在解决飞书知识库目录层级过多，导出麻烦，不能直接到obsidian

**能做：**

- **跟读别人的知识库**。整棵目录树一键拉到obsidian本地变成文件夹，还能把一堆知识库放到一起管理查看，作者更新后你能跟着更新。冲突时默认远端覆盖，你本地的旧改动会先存一份副本，不会丢。
- **跟读单篇分享文档**。别人发的 `/docx/` 链接（不在知识库里的那种），粘贴进来就同步这一篇，作者"持续更新"的文档能长期跟进。
- **多知识库管理**。右下角面板里列出所有知识库，哪个有更新一目了然，可以单个拉，也可以一键全拉。
- **自己的库双向协作**。本地写，飞书看；或者只把本地笔记发布到飞书。支持图片。
- **两种笔记形态**：文档模式（转成飞书在线文档，好看可编辑）和文件镜像（原始 .md 原样上传）。

**不能做：**

- 飞书的**电子表格、多维表格、思维笔记、幻灯片**，以及挂在知识库里的 PDF/Excel 等附件文件，同步不了。插件会在计划里告诉你有几个这样的节点、是什么类型，但内容不会下来。
- 转换不是无损的。飞书文档转 obsidian的Markdown 会变排版，不保证逐字一样。
- 只支持**中国版飞书**（feishu.cn），不支持国际版 Lark；只支持**桌面版 Obsidian**。
- 首次使用要在飞书开放平台建一个应用（一次性，约 5-10 分钟），也就是以你的用户权限读数据，你能读，就能拉。

## 第一步：装插件

方式一：下载构建好的包。到本仓库的 [Releases 页面](https://github.com/wsa0227/feishu-sync-double/releases)，下载最新的 `feishu-wiki-sync-0.2.0.zip`（文件名里的版本号以实际发布为准），解压后把 `feishu-wiki-sync` 文件夹放进你的仓库 `.obsidian/plugins/` 下，重启 Obsidian，在 设置 → 第三方插件 里关掉安全模式并启用。

方式二：源码安装。仓库目录下执行：

```sh
npm ci
npm run install:vault -- "你的仓库完整路径"
```

脚本会先构建再自动装进去，原有配置不受影响。

## 第二步：建飞书应用（一次性）

1. 打开 [飞书开放平台](https://open.feishu.cn/app)，先创建一个**企业自建应用**。进应用后，左侧「凭证与基础信息」页能复制 **App ID** 和 **App Secret**（后面要填到插件里）。

![开发者后台：应用凭证](../步骤图片/飞书开发平台后台应用凭证.png)

![App ID 与 App Secret 的位置](../步骤图片/开发者后台appid和secret.png

2. 左侧「权限管理」→ 点 **开通权限**，把下面这些权限逐个搜出来开通：

| 权限标识 | 干什么用 |
| --- | --- |
| `drive:drive` | 文件读写、查元数据 |
| `wiki:wiki` | 列知识空间、读目录节点 |
| `wiki:node:read`、`wiki:node:retrieve` | 解析别人分享的公开知识库链接 |
| `docx:document` | 文档模式建、读、改文档 |
| `docs:document.media:download` | 下载文档里的图片 |
| `docs:document.media:upload` | 文档模式上传本地图片 |
| `offline_access` | 保持登录，不用天天重新授权 |

![权限管理页](../步骤图片/开发者后台权限页面.png)

3. 登记回调地址：开发者后台 → 左侧「安全设置」→ 重定向 URL 填下面这个，一个字都不能差：

```
http://localhost:7634/callback
```

4. 发布：左侧「版本管理与发布」→ 创建版本（填版本号和更新说明）→ 申请线上发布 一般首次会自动发布，因为权限只有发布后才生效；在「应用发布 → 可用性」里把可用范围设成包含你自己。改过权限要重新发一版才生效。

## 第三步：在 Obsidian 里授权

1. 设置 → 第三方插件 → **Feishu Wiki Sync**，页面上方的"飞书应用与授权"是个抽屉，点开。
2. 填入 App ID 和 App Secret；重定向地址保持默认（要和上一条登记的完全一致），授权范围保持默认。
3. 点 **授权飞书账号**，浏览器会打开飞书授权页 → 选你有权限的账号 → 点同意授权。
4. 回到 Obsidian，"授权状态"显示已授权后，点 **连接测试**，能看到"连接成功，可见知识空间 N 个"就通了。

![插件里的授权设置页](../步骤图片/插件应用授权页面.png)

以后授权过期了不用翻设置：命令面板（Ctrl+P）里运行 **"重新授权飞书账号"** 就行；授权失效时设置页顶部也会有红色提示条。回调地址打不开也没关系，浏览器地址栏里带着 `code=` 的完整链接复制回来，点"手动粘贴授权码"贴进去一样能用。

## 第四步：跟读一个知识库

以别人的知识库为例：

1. 点 Obsidian 右下角状态栏的 **飞书文档**，弹出知识库面板，点 **➕ 添加知识库**。
2. 在飞书里打开那个知识库的任意页面，复制地址栏链接粘贴进来，点 **解析**。插件自动认出空间和节点，不用你去找 space_id。
3. 选**同步范围**：只想拉某个页面往下，选"仅该节点子树"；想拉整个库，选"整个空间顶层"。
4. 本地目录会自动按库名建议好（比如 `飞书同步/AI工具派`），可以改。
5. 选**同步方式**：只看不写选"仅拉取（只读）"；你自己有编辑权限、两边都要写，选"双向协作"。
6. 点 **完成并开始首次同步（预览）**，先看计划：会拉下来几篇、有哪些内容同步不了，都在里面。没问题就执行。

![添加wiki知识库的步骤](../步骤图片/添加wiki知识库的步骤.png)

![同步计划预览](../步骤图片/知识库的预览.png)

预览里那句"另有 2 个远端内容不参与此模式同步：多维表格 2"就是上面说的覆盖面提示——这些内容拉不下来，但你能提前知道数量。

## 第五步：跟读一篇分享文档（/docx/ 链接）

别人发你一个 `https://xxx.feishu.cn/docx/xxxx` 这样的链接：

1. 同样从状态栏打开面板 → 添加知识库 → 粘贴链接 → 解析。插件认出这是单篇文档，自动取文档标题。
2. 选个本地目录（建议按文档名建个文件夹，图片附件也会放里面）。
3. 同步方式固定是**仅拉取（只读）**，点完成后预览、执行。

![添加单篇文档的步骤](../步骤图片/快捷面板步骤1.png)

![单篇文档向导](../步骤图片/添加文档步骤.png)

![同步结果](../步骤图片/同步结果.png)

拉下来的效果：文档正文、图片都在本地，飞书的高亮块转成 Obsidian 的 callout（`> [!info]`），文档里的引用块转成可点的原文链接。

## 日常使用：检查更新和拉取

- 点右下角状态栏，打开知识库面板。所有知识库都在，每行有"拉取 / 检查更新 / 删除"。
- 点 **检查全部更新**（只看不动），哪个库有更新，行下面会标"⬇ 有更新 N 篇"。
- 想全部更新就点 **⬇ 一键拉取全部更新**（确认一次，逐库拉）；只想更新某个库就点那一行的"拉取"。
- 不想每次手点：设置 → 同步模式与行为（抽屉）里有**定时检查更新**，默认是关的。知识库多的话开着也行，它只做检查不拉内容。

## 冲突和删除是怎么处理的

- **默认不删任何东西**。本地删了、远端删了，都只在结果里提示，等你自己确认。
- 只读库：作者改了，远端覆盖你本地，但你被覆盖前的版本自动存到 `.obsidian/feishu-sync/conflicts/`。
- 双向库：两边都改过同一篇时，不覆盖谁，远端版本存成副本，两边原样保留，人工处理。
- 每次同步前都会弹计划让你确认（可以关），执行前还会再核对你本地有没有新改动。

## 几个常见问题

- **改了配置要重新弄吗？** 不用。每个知识库的配置和进度分开存，加新库点"添加知识库"就行，不用来回改。
- **图片在哪？** 文档里的图片下载到对应目录的 `attachments/` 下，笔记里是 Obsidian 的图片引用。
- **状态栏那行字是什么？** 当前知识库、上次同步时间、篇数，有更新时会多个 `⬇N库有更新`。点它打开面板。
- **授权报错了？** 跑"重新授权飞书账号"；还不行就去设置里检查 App Secret 有没有贴错。
- **想把本地笔记发到飞书？** 给自己有编辑权限的库选"双向协作"或"仅推送"，写完同步一下就行。
